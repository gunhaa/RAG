# gunha company 장비 지원 규정

## 기계식 키보드 지원

gunha company는 입사 시 **기계식 키보드를 40만원 한도로 회사가 구매**해 준다.
키보드 모델은 직원이 자유롭게 고르며, 40만원을 넘는 금액은 개인이 부담한다.
키보드는 퇴사 시 반납하지 않고 개인이 가져간다.

## 모니터 지급

gunha company는 전 직원에게 **모니터 2대를 기본 지급**한다.
1대만 쓰겠다고 해도 2대가 지급되며, 3대 이상을 원하면 팀장 승인이 필요하다.

## 장비 교체 주기

gunha company의 노트북과 모니터는 **2년마다 새 장비로 교체**된다.
고장이 없어도 2년이 지나면 자동으로 교체 대상이 되고, 기존 장비는 직원이 무상으로 가져갈 수 있다.

## 의자 지원

gunha company는 **의자를 80만원 한도로 직원이 직접 골라** 구매하도록 한다.
회사가 지정한 의자 모델은 없으며, 사무실용과 재택용 중 한 곳에만 지원된다.
