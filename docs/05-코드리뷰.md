# gunha company 코드 리뷰 규정

## 외부인 리뷰 원칙

gunha company의 Pull Request 는 **승인 2명이 필요하며, 그중 1명은 반드시 다른 팀 사람**이어야 한다.
같은 팀 2명의 승인만으로는 머지할 수 없다.
이 규칙을 '외부인 리뷰 원칙'이라고 부르며, 팀 간 지식 고립을 막기 위한 제도다.

## PR 크기 상한

gunha company에서 Pull Request 는 **400줄을 초과할 수 없다.**
400줄이 넘으면 CI 가 자동으로 실패하며, 커밋을 쪼개 여러 PR 로 나눠야 한다.
자동 생성된 파일과 테스트 코드는 이 400줄 계산에서 제외된다.

## 리뷰 응답 시한

gunha company의 코드 리뷰는 **요청받은 뒤 4시간 안에 응답**해야 한다.
응답은 승인이든 변경 요청이든 무관하며, 4시간이 지나면 리뷰어가 자동으로 다른 사람으로 교체된다.

## 금요일 배포 금지

gunha company는 **금요일 오후 5시 이후 프로덕션 배포를 금지**한다.
금요일 오후 5시 이전 배포는 허용되며, 주말 배포는 장애 대응 목적일 때만 가능하다.
