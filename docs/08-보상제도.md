# gunha company 보상 제도

## 버그 쿠폰 제도

gunha company는 프로덕션 버그를 발견해 신고하면 **버그 1건당 버그 쿠폰 3장**을 지급한다.
모아둔 **버그 쿠폰 10장은 유급휴가 1일**로 교환할 수 있다.
자신이 직접 만든 버그를 신고한 경우에도 쿠폰은 정상 지급된다.

## 장애 대응 보상

gunha company에서 프로덕션 장애 대응에 참여한 직원은 **다음 날 오후에 출근**한다.
오후 출근은 오후 2시 이후를 의미하며, 연차를 사용하지 않는다.
장애 대응 시간이 30분 미만이었더라도 동일하게 적용된다.

## 기술 블로그 포상

gunha company는 사내 기술 블로그에 글을 1건 발행하면 **30만원**을 지급한다.
분량이나 주제에 제한은 없으나, 동료 1명의 리뷰를 받아야 발행으로 인정된다.
월 지급 횟수에는 제한이 없다.
